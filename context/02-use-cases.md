# Use cases

## End user: query → personalized artifact

| # | Query | Input | What gets personalized |
|---|---|---|---|
| 1 | "Estoy con mi pareja, tres horas libres, 50 €, esta noche." | Voice | Offers under €50 for two tonight; romantic tone; reserve CTA for 2 |
| 2 | *Screenshot of a ramen bowl* + "something like this near me, under €20" | Image + text | The brand's own ramen shown first, real price, imagery matching the screenshot |
| 3 | "Friday, 8 friends, two vegans, one celiac, terrace, ~€30 each" | Text | Vegan/GF dishes from the real menu, terrace badge, card sized for sharing in a group chat |
| 4 | *Conference agenda PDF* + "dinner for 6 clients after day 2, private room, €80 pp" | Document + text | Date taken from the PDF, private-room set menu, formal tone, invite-style card |
| 5 | "Sunday brunch, two kids, grandma uses a wheelchair" | Voice | Accessibility shown first, kids' menu, family tone |
| 6 | "Romantic weekend, 2 nights near Barcelona, spa, €400" | Text | Hotel package (room + spa + dinner) priced for those dates |

## Brand: data in → BrandKit

| # | Input | Result |
|---|---|---|
| B1 | Connected Frontify workspace | BrandKit from structured assets and guidelines (high confidence) |
| B2 | Guidelines PDF + menu PDF + website | Draft BrandKit, venues and offerings, reviewed by the brand |
